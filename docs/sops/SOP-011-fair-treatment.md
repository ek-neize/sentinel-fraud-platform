# SOP-011 Fair treatment and protected attributes

## §1 Protected attributes
Gender, age, ethnicity, religion and similar characteristics must never be used to decide
whether to investigate, contact, block or clear. The Sentinel model does not use gender or
age as inputs. Investigators must not use them either, even if they are visible in source
systems.

## §2 Consistent handling
Similar facts get similar treatment. Monitoring reports recall by group; the current report
shows a gap between groups that Fraud Analytics is investigating. Investigators follow the
same procedures for every customer regardless of group.
